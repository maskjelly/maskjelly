## Selected work

- **[instantKV](https://github.com/maskjelly/instantKV)** — Local agent memory in Rust, with BM25 search, durable checkpoints, and MCP. Source MVP.
- **[Morse](https://github.com/maskjelly/morse)** — A Rust agent runtime with remote execution, session replay, and a separate agent for progress updates.
- **[TiVM](https://github.com/maskjelly/TiVM)** — UI testing in disposable Linux desktops, with screenshots, video, and replay. Pre-1.0 prototype.
- **[rushort](https://github.com/maskjelly/rushort)** — A Rust HTTP service with SQLite durability, a verified load generator, and documented benchmarks.
- **[Plain Corners](https://github.com/maskjelly/plain-corners)** — A native macOS utility for adjusting window corners and restoring previous settings. Working preview.
